# Priyanka Thakuri — Portfolio

Personal portfolio site built with React, Vite and Tailwind CSS, showcasing Laravel/PHP projects and full-stack web development skills.

**Live demo:** _add your deployed URL here_

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- lucide-react icons

## Sections

- Hero introduction
- About
- Skills (Frontend, Backend, Database, Tools)
- Featured projects with GitHub links
- Experience & education
- Contact (with a mail-based contact form)

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
